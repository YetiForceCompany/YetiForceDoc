## 🧪 Public demo of the YetiForce system

YetiForce provides a **complete and fully functioning demo** of the system that you can test without any obligations. This is a great way to familiarize yourself with the interface and features before installation.

### 🌐 Demo address

**YetiForce demo:** <a href="https://demo.yetiforce.com" target="_blank">demo.yetiforce.com</a>

### 🔑 Demo credentials

Use one of the following accounts to log in:

- **Admin level permissions**
  - Login: `admin`
  - Password: `admin`
- **User level permissions (basic)**
  - Login: `demo`
  - Password: `demo`

### ⚠️ Technical Info

- **Data Status:** The Demo is **refreshed daily** at: 7:00 AM, 12:00 PM, 3:00 PM, 10:00 PM CET. Any changes you make will be lost after the refresh.
- **Version:** This is the most recent development version of the system that includes all the latest fixes. Due to that, it's also likely to include some bugs and errors.

## ❓ FAQ

- **What's the difference between a demo and a production version?** The demo runs on a shared server and is periodically reset. You install the production version on your own server with full control over your data.
- **Can I configure the demo my way?** Yes, but the changes will be removed on the next refresh.
- **Where can I download the system to install on my own?** Go to the [Download YetiForce](/introduction/download) page.
